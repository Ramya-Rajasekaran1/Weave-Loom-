## 🧵 About

**Loomina** is an interactive, tactile typographic canvas where your keystrokes weave living threads. Combining physical string tension simulation with generative letterforms and acoustic sound synthesis, Loomina turns typing into a tactile, multi-sensory loom experience.

---

## ✨ Features

- **Elastic String Physics:** Characters are anchored by pins and woven with threads that sag, resonate, and rebound using real-time Verlet integration.
- **Direct Interaction:** Hover near threads to feel magnetic cursor attraction, or click and pluck strings to strum physical vibrations.
- **Acoustic Synthesizer:** Real-time Web Audio API synthesizer that produces acoustic resonant chord strums as strings vibrate.
- **Kinetic Motion Effects:** Switch between *Breathe*, *Wind Gust*, *Luminous Needle*, and *Twin Shuttles* to animate your typography.
- **Falling Snowflakes / Glowing Embers:** Toggleable ambient particles gently drifting across the canvas.
- **Curated Color Palettes:** Figma Prism, Electric Tokyo, Sunset Gradient, Neo Botanical, Deep Cyber, and Monochrome Luxe.
- **Framed Studio Canvas:** Switch seamlessly between Fullscreen Canvas, 4:5 Poster Artboard, and 1:1 Square frames.
- **Vector & High-Res Export:** Download high-resolution PNG snapshots or clean vector SVG artwork directly from the studio.

## ⌨️ Controls & Shortcuts

| Action | Control |
| :--- | :--- |
| **Weave Characters** | Type any letters or numbers |
| **Snip Yarn** | <kbd>Space</kbd> (creates physical cut thread ends) |
| **Unravel** | <kbd>Backspace</kbd> (smooth physics unravel) |
| **Clear Canvas** | <kbd>Enter</kbd> or <kbd>Esc</kbd> |
| **Pluck / Strum** | Click & drag across strings |
| **Toggle Audio** | Click the Audio button in the dock |
| **Toggle Snowflakes** | Click the Snow button in the dock |

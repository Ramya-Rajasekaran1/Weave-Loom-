## Design Context

### Users & Purpose
- **Audience**: Design engineers, creative coders, recruiters, and creative professionals exploring high-craft interactive portfolio artifacts.
- **Job to be Done**: Create a mesmerizing, tactile generative typography and poster engine inspired by Type Garden with Figma brand colors, real-time string physics, and instant vector/poster export.
- **Emotions**: Tactile delight, effortless creative play, visual sophistication, wabi-sabi precision.

### Brand Personality & Voice
- **Tone**: High-craft, tactile, artisanal, minimalist, computational precision.
- **Keywords**: Tactile, Organic, Geometric, Refined, Kinetic.
- **References**: Type Garden (Akshat Agarwal), Figma Design Systems, Dieter Rams functional minimalism, Japanese Sumi & Textile Craft.

### Aesthetic Direction
- **Theme**: Dark mode canvas with pitch-black / obsidian / paper themes.
- **Color Palette**: Figma Brand Colors (`#F24E1E`, `#FF7262`, `#A259FF`, `#1ABCFE`, `#0ACF83`) alongside Rose Noir, Paper, Midnight, Citrus, Orchid, Moss, Tomato, and Butter.
- **Typography**: 
  - Serif Display: Newsreader / Playfair / Bodoni for expressive center typography.
  - UI Monospace: JetBrains Mono / SF Mono / Courier for metadata, shortcuts, and keybindings.
  - Sans: Plus Jakarta Sans / Inter for UI badges and control labels.

### Design Principles
1. **Direct Manipulation**: Every keypress has an instantaneous, physical reaction (Verlet string simulation, scissors snip, unravel).
2. **Invisible Interface**: The controls stay whisper-quiet at the edges so typography remains the hero.
3. **Authentic Physics**: Strings sag, twang with acoustic harmonics, and drape naturally with catenary curve relaxation.
4. **Export Readiness**: Every screen is one click away from vector SVG, high-res PNG, or animated poster output.
